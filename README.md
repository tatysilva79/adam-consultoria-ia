# ADAM Consultoria IA

Plataforma independente de consultoria estratégica para perfis TikTok.

## Etapa 1 — Protótipo visual
Interface demonstrativa com dashboard, clientes, nova consultoria, diagnóstico, inteligência de vídeos e lives, planejamento de 10 dias, tendências, horários, aprovação administrativa e relatórios.

**Atenção:** nesta etapa os dados são fictícios e identificados como demonstração. Não há conexão real ao TikTok, IA, autenticação, banco de dados, envio de arquivos nem emissão de relatório final.

## Identidade
Roxo #7C3AED, dourado #FFD54A, lilás #A78BFA. Mascote e engrenagem oficiais deverão ser adicionados como assets autorizados.

## Tecnologia
React + TypeScript + Vite + Tailwind CSS + lucide-react.

## Rodar localmente
```sh
npm install
npm run dev
```

## Separação obrigatória
Repositório independente do ADAM TikTok. Nunca compartilhar secrets, dados pessoais ou backend com o sistema original. Não publicar sem autorização.

## Fluxo futuro
Cadastro -> Coleta autorizada -> IA com evidências -> 10 roteiros -> Revisão master -> Aprovação -> Entrega.
